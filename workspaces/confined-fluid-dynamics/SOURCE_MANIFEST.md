## 6. Availability and integrity rules

1. This file is a **manifest only**. No PDF, ZIP, worksheet, audio file or prior deliverable is uploaded into GitHub by creating this Markdown file.
2. Project source access may depend on the ChatGPT project and file attachment context. Do not treat `/mnt/data/` as a persistent GitHub-accessible path.
3. To reproduce a cited paper, identify its ZIP, member path and SHA-256, then verify bibliographic metadata from that file itself.
4. Control documents and geometry references guide analysis; prior summaries and syntheses are secondary, not primary proof.
5. Keep any new files inside `workspaces/confined-fluid-dynamics/` unless separately authorized. Record substantive changes to repository files in `config/file-metadata.json`.
6. When adding actual source files later, update this manifest with their GitHub paths, original archive provenance, bytes and SHA-256, and remove any resulting false claim of absence.

- The 14 Project index records are identified by ID, but byte-wise equivalence of records sharing the same display name has not been established.
- Academic references cited in execution summaries are not assumed to be attached; only the listed physical files and archive members are in this manifest.
