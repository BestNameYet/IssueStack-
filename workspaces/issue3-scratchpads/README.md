# Issue #3 Scratchpad Workspace

Snapshot of all comments from [Issue #3](https://github.com/BestNameYet/IssueStack-/issues/3).

- `scratchpads/`: individual original GitHub comment bodies, unchanged (UTF-8).
- `manifest.json`: permanent comment and job IDs, URLs, sizes and SHA-256 digests.
- `all-comments.json`: the same original comment bodies in machine-readable form.
- `issue3-scratchpads.zip`: portable snapshot with all of the preceding files.

To refresh, run the GitHub Actions workflow `Publish Issue 3 Scratchpads Workspace`.
