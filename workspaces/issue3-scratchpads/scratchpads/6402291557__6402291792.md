[\`runtime/issue6-route.cjs\`](https://github.com/BestNameYet/CommandLine/blob/main/runtime/issue6-route.cjs) requires the event's owner identity and authorized comment ID (passed through workflow environment) to select exactly one route: ordinary \`gh\`, \`commit\`, or \`meta\`. Unselected human comments undergo normalization; invalid/bare commands do not run.

**Ordinary CLI.** [\`runtime/issue6-gh-command.cjs\`](https://github.com/BestNameYet/CommandLine/blob/main/runtime/issue6-gh-command.cjs) parses quotes/escapes, invokes Node \`spawnSync("gh", args)\` without a shell (90-second process timeout, 1 MiB output buffer), wraps actual exit code/stdout/stderr as \`gh-command-result\`, posts to Issue #7, places an Issue #6 pointer/reuses hidden blank response slots, then resets the input. The standard workflow grants \`contents:read\` and \`issues:write\`: the label **read-only** is correct for repository contents permissions, **not** a guarantee that all \`gh api\` operations are incapable of changing Issues. Treat write-capable Issue operations as privileged within the owner-controlled input.

**Commit routing.** [\`runtime/issue6-commit.cjs\`](https://github.com/BestNameYet/CommandLine/blob/main/runtime/issue6-commit.cjs) verifies origin, freshness of input, JSON file-object shape, path/traversal, byte limit, destination file SHA, and publishes \`gh-commit-result\` with created/updated/unchanged/failed. [\`issue-6-commit.yml\`](https://github.com/BestNameYet/CommandLine/blob/main/.github/workflows/issue-6-commit.yml) grants \`contents:write\`, \`issues:write\`. This separates repository write privileges from the standard \`gh\` route; workflow files are governed by a stricter integration-promotion rule.

**Meta route.** [\`issue-6-meta.yml\`](https://github.com/BestNameYet/CommandLine/blob/main/.github/workflows/issue-6-meta.yml) runs Node 22 and the meta controller/console tests before [\`workspaces/meta-instructor/issue6-adapter.cjs\`](https://github.com/BestNameYet/CommandLine/blob/main/workspaces/meta-instructor/issue6-adapter.cjs). Separate managed-action enforcement is narrower than ordinary connected tools.

[\`runtime/execute-js.cjs\`](https://github.com/BestNameYet/CommandLine/blob/main/runtime/execute-js.cjs) creates a temporary source file, optionally installs npm dependencies with \`--ignore-scripts\`, spawns Node in the temporary directory, streams stdout/stderr, enforces optional user-configured time/output limits and cleans up.
